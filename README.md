# Sprint 4 - Portafolio

Portafolio personal de Mariana Hernández desarrollado con HTML y CSS puros siguiendo el diseño original del archivo Figma.

## Descripción

Este proyecto replica con precisión el diseño del Sprint 4: Portafolio, incluyendo tipografías locales, imágenes originales, layout responsivo y efectos visuales desarrollados únicamente con CSS.

## Tecnologías utilizadas

- HTML
- CSS
- Fuentes locales con `@font-face`

## Estructura del proyecto

- `index.html`
- `styles/normalize.css`
- `styles/style.css`
- `images/` (imágenes y iconos originales)
- `fonts/` (Open Sans y Archivo Black locales)

## Cómo ejecutar

1. Abrir `index.html` en el navegador.
2. No se requiere servidor o dependencias adicionales.
