# Portafolio — Julian Cotrino

Sitio web de portafolio personal, responsivo, que presenta mis habilidades y los proyectos que he desarrollado durante el curso.

## Tecnologías y técnicas utilizadas

- HTML5 semántico
- CSS3 (Flexbox, Grid, `@media` para diseño responsivo, `@font-face`)
- Diseño adaptado a tres resoluciones: 320px, 768px y 1440px
